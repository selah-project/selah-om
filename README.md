# Katabbiiwwan Qulqulluu Ibrootaa (Tanakh) — Hiikkaa Afaan Oromoo

Hiikkaa Afaan Oromoo kan Katabbiiwwan Qulqulluu Ibrootaa (Tanakh)
— lakkoofsa lakkoofsaan, qubee jalqabaatiif amanamaa.

## Ibrootaa — Dursa

Hiikkaan kun si gara Ibrootaatti geessuu dha — bakka ishee bu'uuf
miti. Yeroo hunda kan dubbifamu Ibrootaa dha: qubeen ishee,
sagaleewwan ishee, mallattoowwan ishee. Barruun Afaan Oromoo kan
gadii foddaa dha, bakka-bu'aa miti. Lamaan yoo gargar ba'an,
dhugaan kan Ibrootaa ti.

## Maqaa

Bakka Maqaan qubee afurii dhaabatu hundatti nuti **Yahwe**
barreessina — moggaasni tokko illee, jechi waliigalaa tokko illee
bakka isaa hin fudhatu. **Yihoowaa** (bifa makaa) hin barreessinu,
**Waaqayyo** (jecha Macaafni Afaan Oromoo Waaqaaf itti fayyadamu)
teessoo Maqaa irratti hin keenyu, **Gooftaa** (moggaasa — Maqaa
haquu dha) hin barreessinu, **Waaqa** illee teessoo Maqaa irratti
hin keenyu. Maqaan bakka hundatti akkuma jirutti hafa — bakka
Maqaan dhaabatu yeroo hunda akka mul'atuuf.

## Aleph-Tav — ⟨את⟩

Himoota Afaan Oromoo keessatti mallattoo **⟨את⟩** ni argita.
Ibrootaa keessatti אֵת jecha xiqqaa kan wanta gochaan irra ga'u
agarsiisu dha. Afaan Oromoo wal-gitaa sirrii hin qabu, hiikkaawwan
baay'eenis calʼisanii isa haqu. Nuti golboo keessatti isa eegna,
akka mul'atuuf — inni qaama dhaʼannaa afaan ishee ti. Haquu
mannaa, jiraachuu isaa mul'isuu filanne.

## Jechoota ⟨golboo⟩ keessaa

Golboon ⟨akkasii⟩ jecha **Ibrootaa keessa hin jirre** agarsiisa —
guuttaa himni Afaan Oromoo barbaadu. Mallattoo malee walitti
makuu mannaa golboo keessa keenya — jechootni jalqabaa fi
dabalatootni Afaan Oromoo barbaachisan yeroo hunda gargar akka
mul'ataniif. Guuttaawwan golboo keessaas Afaan Oromoo qofa.

## Maqootaa fi Moggaasota

Jechootni Ibrootaa kan Qulqulluutti garagalan — **Eloohiim**,
**Eel**, **Shaddaay**, **Adoonaay**, **Yaah** — sagalee isaaniitiin
barreeffamu. Jecha tokkotti walitti hin qabnu; tokkoon tokkoon
isaanii baʼaa mataa isaanii baatu. Maqoonni namootaa fi
magaalotaas bifa Ibrootaa hordofu: Avrahaam, Yitschaaq, Yaʼaqoov,
Moshee, Yerushaalayim.

## Jechoota Mallatteeffaman

- **kheesed** (חֶסֶד) — jaalala kakuu hin sochoone. «Gaarummaa»
  qofa miti, «araara» qofa miti. Jechi Afaan Oromoo tokko qofaan
  isa hin baatu.
- **She'ool** (שְׁאוֹל) — iddoo warra du'anii, akkuma Ibrootaan
  jedhu. Gonkumaa «si'ool ibiddaa» miti.
- **Maashiyaak** (מָשִׁיחַ) — **Maashiyaak / Kan Dibame** —
  sadarkaa Tanakh irratti, gonkumaa «Kiristoos» miti.
- **nefesh**, **ruwak**, **kaavood** — akkaataa iddootti (lubbuu
  yookiin jireenya, hafuura yookiin bubbee, ulfina yookiin
  ulfaatina) — jecha tokkotti hin hidhaman.

## Tokkoon Tokkoo Lakkoofsaa Ifa Mataa Isaatiin

Tokkoon tokkoon lakkoofsaa waan iddoo isaatti jedhu dubbata —
amantii Ibrootaa kan Eloohiim tokko taʼe keessatti isa dubbifna.
Barumsa boodaa duubatti hin deebifnu; xumura seenaa jalqaba
isheetti hin dubbifnu. Jechi iddoo isaatti baʼaa isaa akka baatu
dhiifna — kaayyoon kanuma.

## Caasaa Faayilotaa

Lakkoofsa tokko — faayila tokko: lakkoofsichi mataan isaa fi
hiikkaan tokkoon tokkoo jechaa Ibrootaa isaa cinatti — jechi
Ibrootaa hundi jecha Afaan Oromoo isaa fuula duratti akka
dubbifamuuf.
